# LiteTable Docs

Official documentation repository for the **LiteTable** multi-language ecosystem. Powered by VitePress and hosted on GitHub Pages.

## 🚀 Overview

This repository houses the centralized documentation site for the LiteTable database architecture, ensuring clean guides, API references, and practical code examples across multiple programming languages.

## 📦 Documented Implementations

- **[PHP](https://github.com/ortizaad1994/litetable-php)**: High-performance PDO wrapper utilizing horizontal traits, strict typing, and fluent query builders.

- **[Go](https://github.com/ortizaad1994/litetable-go)**: Lightweight database management and query abstractions built for concurrent backend services.

- **[.NET](https://github.com/ortizaad1994/litetable-dotnet)**: Clean repository patterns and safe SQL bindings for C# and ASP.NET Core applications.

- **[Python](https://github.com/ortizaad1994/litetable-python)**: Fast database access and query structuring tailored for modern Python and FastAPI architectures.

## 🛠️ Local Development & Contribution

1. **Install Dependencies:**
   ```bash
   npm install

```

2. **Run Development Server:**
```bash
npm run docs:dev

```


3. **Build Static Files:**
```bash
npm run docs:build

```
